# 스토어 심사 자산

여기에는 심사·스토어 게시에 쓰는 샘플과 문안을 둡니다. **규격을 임의로 만들지 않습니다.**

## 채워야 할 것

아임웹 담당자 제공 콘텐츠 가이드의 실제 규격을 확인한 뒤 다음을 준비합니다.

- 앱 아이콘(가이드가 정한 크기·형식)
- 스크린샷/데모 이미지(가이드가 정한 크기·개수)
- 앱명·짧은 설명·긴 설명·태그
- 가격/체험/지원/정책 정보

현재 위 가이드 본문 접근에 실패해 이미지 크기·필수 개수는 **미확인**입니다. 담당자에게 문서
export/대체 링크를 요청합니다. 확정 전에는 크기를 추측해 만들지 않습니다.

- 설치 없이 볼 수 있는 데모: `/demo`(편집·XLSX·인쇄).

## 심사용 샘플 시나리오

1. `/demo`에서 합성 상품 10개를 불러와 3개 품목만 남깁니다.
2. 수신 회사명·유효기한·납기/가격 조건을 입력하고 협의 단가를 수정합니다.
3. XLSX를 내려받고 인쇄 화면에서 A4 PDF로 저장합니다.
4. 설치된 테스트사이트에서는 실제 상품을 불러와 저장→확정→복제→이력까지 확인합니다.
