# 스토어 문안 초안

규격(글자 수 제한 등)은 콘텐츠 가이드 확인 후 맞춥니다. 아래는 초안입니다.

## 앱명(안)

견적서 자동 작성

## 한 줄 설명

아임웹 상품을 골라 협의 단가로 견적서를 만들고 XLSX·A4 PDF로 내보냅니다.

## 상세 설명

기업·기관·단체 주문을 받는 판매자를 위한 견적 도구입니다. 아임웹에 등록한 상품과 옵션을 그대로
불러와 수량과 협의 단가를 입력하고, 거래처 결재에 쓰는 견적서를 만듭니다.

- 아임웹 상품·옵션 검색 후 견적에 추가
- 수신 회사명·유효기한·납기/배송·가격 조건·비고 입력
- 초안 자동 저장, 확정 버전 스냅샷, 이전 견적 복제
- 같은 확정본으로 XLSX 다운로드 + A4 인쇄/PDF 저장
- 공급자 정보 설정(과거 확정본에 소급되지 않음)
- 사이트별 데이터 분리(다른 사이트 문서 접근 차단)

## 하지 않는 것

- 주문 생성·수정, 장바구니, 결제 링크, 재고 예약
- 회원·주문 개인정보 조회, 자동 발송, 전자서명, 공개 공유 URL
- 부가세 자동 계산, 세금계산서 발행, 외화·다국어
- 버튼 하나로 PDF 파일을 직접 만드는 기능(브라우저 인쇄 저장만 지원)

견적서는 주문 전 제안이며 결제 완료나 주문 생성을 의미하지 않습니다.

## 요청 권한

- `site-info:read`, `site-info:write`: 사이트/유닛 확인, 연동완료·연동해제
- `product:read`: 상품·옵션 조회

회원·주문·결제·리뷰·상품 쓰기 권한은 요청하지 않습니다.

## FAQ(안)

**Q. 상품 단가가 실제 결제 금액인가요?**
A. 아닙니다. 할인·쿠폰·회원가 반영 전 판매가이며, 협의 단가의 제안값입니다.

**Q. PDF 파일을 바로 내려받을 수 있나요?**
A. 아닙니다. 인쇄 전용 화면에서 브라우저의 인쇄/PDF 저장을 씁니다.

**Q. 부가세가 자동 계산되나요?**
A. 아닙니다. 가격 조건에 세금 포함 여부를 적어 주세요.

**Q. 앱을 어떻게 해제하나요?**
A. 앱 안의 연동 해제를 사용합니다. 해제하면 토큰이 삭제되고 다음 회차 청구가 중단됩니다.
